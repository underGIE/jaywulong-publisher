jaywulong publisher is a personal command-line tool. It uploads finished music mixes from one laptop to one YouTube channel, Jay Wulong (@wulongJAY), owned by the same person who runs the tool.

It uses the YouTube Data API and the YouTube Analytics API (YouTube API Services) to:

  • upload a video the owner has already reviewed and approved, with its title, description, tags and thumbnail;
  • add that video to one of the owner's own playlists and schedule its publication;
  • read the owner's own channel statistics into a private local log.

There is no public interface, no sign-up, and no other user. Nobody else can run it, connect to it, or see its data.
