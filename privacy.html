1. What this tool is

jaywulong publisher ("the tool") is a personal command-line program run by its sole owner on the owner's own computer. It has one user: the owner. It publishes videos to, and reads statistics from, one YouTube channel that the owner controls (@wulongJAY).

2. Use of YouTube API Services

The tool uses YouTube API Services (the YouTube Data API v3 and the YouTube Analytics API). By using it, the owner is also bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

3. What data the tool accesses

Through Google's OAuth 2.0 consent, and only for the owner's own Google account and channel, the tool accesses:

  • Channel identity (channel id and title) — to confirm it is connected to the right channel.
  • Video upload and metadata — to upload the owner's own videos and set their title, description, tags, thumbnail, playlist and scheduled publish time.
  • Playlists — to list and add to the owner's own playlists.
  • Channel analytics (views, watch time, subscribers, and, if ever monetised, estimated revenue) — to keep a private performance log.

The tool does not access any data belonging to other YouTube users, viewers, commenters or channels. It does not read comments, subscriptions, watch history or any personal information of anyone other than the owner.

4. How data is stored and shared

  • The OAuth token is stored in a file on the owner's computer, readable only by the owner's user account. It is never transmitted anywhere except to Google's own API endpoints.
  • Analytics figures are written to plain-text log files on the owner's computer.
  • No data is shared, sold, transferred or disclosed to any third party. No data leaves the owner's computer except in requests to Google's APIs.
  • No cookies, trackers, advertising identifiers or analytics services are used by the tool or by this website.

5. Data retention and deletion

Stored data (the token and the local logs) is kept only as long as the owner needs it and can be deleted at any time by deleting the files. Authorised API data is refreshed on each run and not accumulated beyond the local log. Google-side access can be revoked at any time at https://myaccount.google.com/permissions; revoking access immediately stops the tool from working until re-authorised.

6. Children

The tool has no users other than its adult owner and is not directed at children.

7. Changes

If this policy changes, the new version will be posted on this page with a new effective date.

8. Contact

Questions about this policy: message the channel @wulongJAY via its YouTube About page, or the support e-mail address registered on the tool's Google Cloud OAuth consent screen.
